# Mentions légales et crédits par produit

Version 1.0 du 24/10/2026. Chaque fiche peut être copiée dans le `description.txt` du mod, dans la page « Crédits » de
l'appli ou dans la release GitHub. Les crédits de détail viennent de `registre_creations.json`.

Contact pour tous les produits : Discord Truck So Clean France, https://discord.gg/trucksocleanfrance

## Modèle de mention

À utiliser seulement pour ce que TSCF a réellement créé :

> Création originale Truck So Clean France (TSCF). Conception et réalisation : Poutine / TSCF. Tous droits réservés,
> sous réserve des licences et droits des composants tiers identifiés ci-dessous.

Pour un mod qui modifie un modèle tiers, on remplace la première phrase par :

> Création Truck So Clean France (TSCF) réalisée sur un modèle de <auteur>.

Une mention de copyright informe ; elle ne prouve pas à elle seule la propriété et n'empêche pas la copie.
