JUGE DE L'ATELIER SPARTAN STUDIO (meme methode que TSC Graphics)

But : dire si un rendu de livree de l'atelier ressemble a un vrai camion, pour aider l'IA de l'atelier.
C'est UN critere : Mendy tranche toujours (« Je garde / Je jette »).

Sur le PC (Python + torch, par ex. le venv_neural de TSC Graphics) :
1) Photos reelles libres (CC0 / CC BY seulement, auteur + source dans manifeste.json) :
     python collecte_photos.py --sortie photos_reelles --max 400
2) Rendus de l'atelier : bouton « Capture » de Spartan Studio, vues de cote et 3/4, mis dans captures_atelier\
   (cadrer le camion en grand : le fond du studio n'existe pas sur les vraies photos).
3) Juge (poids DINOv2 deja sur le PC : tsc_graphics\poids_externes, timm/vit_small_patch14_dinov2.lvd142m, Apache 2.0) :
     python juge_atelier.py --poids ...\model.safetensors --reel photos_reelles --rendus captures_atelier

Lecture : realisme 1,00 = aussi proche du reel qu'une vraie photo jamais vue (1 photo sur 10 mise de cote, crc32 du nom).
Plus bas = plus « jeu video ». « pire morceau » montre la zone la moins credible.
Les photos ne sont jamais redistribuees ni mises dans un mod. DINOv2 n'est jamais livre aux joueurs.
Test sans poids ni reseau : python test_juge_atelier.py
